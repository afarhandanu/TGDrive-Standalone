# Fitur The Great Drive

## Unduh dan simpan
- Tempel tautan, terima tautan/file dari menu Bagikan Android, atau pilih berkas dari ponsel.
- Tujuan Lokal, Google Drive, atau keduanya; folder mengikuti site/username/jenis media.
- Pilihan kualitas video dan audio, subtitle, thumbnail, serta metadata JSON.
- Batas item dapat dikosongkan untuk tanpa batas. Pengaturan terakhir tetap tersimpan.

## Instagram dan situs lain
- Unduh video, Reel, foto, dan carousel melalui jalur ekstraksi yang tersedia.
- Pemilih Story dengan thumbnail, pratinjau, pilihan beberapa item atau semua.
- Login Instagram, X, dan situs HTTPS lain; situs tersimpan dapat dibuka kembali lewat tombol.
- Impor cookies.txt, serta mode profil/album dan filter tanggal untuk jalur yang mendukung.
- Dukungan situs mengikuti extractor dan hak akses akun; beberapa konten memerlukan login.

## Berkas dan impor
- Impor Instagram JSON/ZIP dengan pilihan kategori, rentang tanggal, serta hasil folder atau ZIP.
- Unduh magnet, tautan torrent, dan berkas .torrent.
- Gabungkan video dan audio memakai FFmpeg pada perangkat yang didukung.

## Google Drive
- Unggah ke folder pilihan dengan opsi lewati nama sama dan verifikasi checksum.
- Jelajahi dan cari file, buat folder, ubah nama, pindahkan file, beri bintang, dan pindahkan ke Sampah.
- Buat atau cabut tautan publik dari pengelola Drive.

## Antrean dan data
- Pantau progres, batalkan tugas, jeda antrean, dan ulangi unduhan yang gagal.
- Buka detail hasil serta log error; ekspor dan pulihkan riwayat dan daftar situs.
- Administrasi perangkat untuk ringkasan antrean, akun, riwayat, dan pembersihan cache.

## Pindahkan folder lama
- Menu Berkas menyediakan migrasi TGDrive ke The Great Drive untuk Lokal dan Google Drive.
- Simpan file lama: salin ke folder baru dan pertahankan sumber.
- Hapus file lama: salin, verifikasi isi, lalu hapus sumber Lokal atau masukkan sumber Drive ke Sampah.
- Struktur subfolder dipertahankan. Salinan identik dapat dipakai lagi; isi berbeda tidak ditimpa.
- Progres dan hasil tersedia di layar pemindahan; proses dapat dihentikan lalu dijalankan ulang.
- Lokal memproses file milik instalasi aplikasi ini. Drive memproses file biasa di bawah folder TGDrive pada induk yang dipilih; dokumen Google dan pintasan dilewati.
- Folder sumber yang kosong tetap ada. File lama yang tidak lagi dimiliki instalasi ini memerlukan pemindahan lewat pengelola file.
